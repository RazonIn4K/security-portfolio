## How I document my work

Each write-up will explain the question investigated, environment and access level, evidence examined, conclusions, setbacks, and recommendations. I will distinguish findings from assumptions and recommendations from changes actually made, and describe any assistance used.

Published evidence will be redacted to protect shared environment identifiers and other participants. Lab flags and answer keys will be omitted. This portfolio describes training work; each completed investigation will link to its supporting write-up.

See the [investigation template](templates/investigation-template.md) for the structure.
